# D3MON World

The redesign of D3MON.CO as an immersive 3D world: the Callers / Bots / Chart Scripts triangle rising into a pyramid, with the Battle of the Bots arena inside and the trade floor at the peak.

**Status: planning.** Nothing here is built or served by the site yet. The real build will be a separate preview page (`/world`), delivered as pull requests.

| Document | What's in it |
| --- | --- |
| [VISION.md](VISION.md) | The owner's brief: what must stay, what can change, the pyramid idea. |
| [PLAN.md](PLAN.md) | The proposed technical approach: engine, device levels, live data, ads, PR order. |
| [SITEMAP.md](SITEMAP.md) | Every page and section today, who uses it, and where it goes in the 3D site: the plan for the tidy-up. |
| [QUESTIONS.md](QUESTIONS.md) | Decisions waiting on the owner, and decisions made (with dates). |
| [INSPIRATION.md](INSPIRATION.md) | Every image and video the owner sent, prompts that worked, and lessons from award-winning sites. |
| [`inspiration/`](inspiration/) | The image and video files themselves. |
| [`mockup/`](mockup/) | The throwaway prototype behind the sample videos. |

## How we keep this folder

- **New inspiration:** save the file in `inspiration/` with the next number (`05-…`). Add a row to INSPIRATION.md saying what to take from it.
- **A question answered:** move it to *Decided* in QUESTIONS.md with the date, then update PLAN.md.
- **Never secrets** (keys, passwords, server addresses, emails), as everywhere in this repo.
- **Sample data stays labelled as sample data.** Nothing shown publicly may present made-up stats as real or verified.
