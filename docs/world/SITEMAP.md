# D3MON site map

Every page and section the site has today (2026-10-18), who uses it, and where it goes in the 3D site. This is the plan for the big tidy-up: when the 3D site is built, each row is moved, merged or retired as written here. **Every existing control stays somewhere** unless a row says "retire".

The 3D site has four places (see [BLUEPRINT.md](BLUEPRINT.md)), plus two menus:

| Place | What it is now, with the tournaments |
| --- | --- |
| **Outside** | The pyramid. Billboards and the way in |
| **Grand Hall** | The live **trading floor**: the tournaments, the round clock and every bot's call live |
| **Helix** | Browse every bot, script and caller as a card. Tap for their profile |
| **Trade Floor** (the peak) | The community: chat, voice, streams |
| **My D3MON** (menu) | Everything about you: your bots, keys, account, messages, coin |
| **Admin** (menu, admins only) | One admin hub for everything admins do |

## Admin

| Today | In the admin hub |

The D3MON logo (opens the map), **Join D3MON**, **Menu** (World, Tournaments, Community, My D3MON), **Admin** for admins only, the account, and two small icons for quality and sound. Nothing else.
